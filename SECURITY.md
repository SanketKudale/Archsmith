# Security policy

Report vulnerabilities privately through the repository security advisory feature; do not open a public issue containing exploit details or secrets.

Archsmith generates application architecture, not a security boundary. Generated runtime checks are signals with platform-dependent confidence. Root/jailbreak, VPN, proxy, capture, mirroring, emulator, and integrity signals can be unavailable, ambiguous, or bypassed. Use least privilege, server-side authorization and attestation, secret rotation, and independent security review for sensitive applications.
